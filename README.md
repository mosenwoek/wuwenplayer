# 无闻影视 · WuWenCinema

> 看见故事，感受无闻

Flutter + Node.js + MobileVLCKit 全能影视播放器。基于 UZN 1.1.9 开源重制。

## 功能

- **Emby / Jellyfin / Plex** 客户端
- **IPTV** 直播（M3U 播放列表 + EPG 节目单）
- **TMDB / 豆瓣** 元数据刮削
- **WebView 视频嗅探**（fetch / XHR / MSE / TextDecoder 全 hook）
- **弹幕** 系统（内嵌 Node 弹幕服务）
- **WebDAV** 备份（坚果云）
- 内嵌 **Node.js** 运行时（catpaw 服务实例管理）
- **MobileVLCKit** 内核（格式通吃）
